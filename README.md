## :dart: O guia para alavancar a sua carreira

> Delphi é o ambiente de desenvolvimento rápido (RAD) criado pela Borland em 1995 e mantido hoje pela Embarcadero: a linguagem é o Object Pascal, e com um único código-fonte dá para compilar aplicações nativas para Windows, macOS, iOS, Android e Linux. Depois de 30 anos, o Delphi continua vivo no Brasil — sustenta sistemas bancários, ERPs, softwares de gestão pública e aplicações corporativas em atividade até hoje, e segue recebendo versões novas: a mais recente é o Delphi 13 "Florence", com uma edição Community gratuita e um assistente de IA agêntico (o "Kai") que já se integra com o Claude. Este guia reúne documentação oficial, cursos, livros, ferramentas e comunidades para quem vai dar manutenção em um sistema legado, entrar em uma vaga de Delphi ou simplesmente conhecer a linguagem. Os recursos gratuitos e em português vêm primeiro em cada seção, e todo link foi verificado.

## 🗺️ Roadmap

- [Embarcadero — Delphi (visão geral oficial)](https://www.embarcadero.com/products/delphi) — Página oficial do produto: o que é o Delphi, para que serve e quais plataformas ele compila.
- [Delphi — 30+ anos de história (Embarcadero)](https://delphi.embarcadero.com/) — Linha do tempo oficial de todas as versões, do Delphi 1 (1995) ao Delphi 13, com os principais recursos adicionados em cada uma.
- [Delphi (software) — Wikipédia (PT-BR)](https://pt.wikipedia.org/wiki/Delphi_(software)) — Verbete em português com histórico da linguagem, das versões e da relação com a VCL e a FireMonkey.
- [Delphi (software) — Wikipedia (EN)](https://en.wikipedia.org/wiki/Delphi_(software)) — Verbete em inglês, mais detalhado sobre a linha do tempo técnica e as mudanças de dono (Borland → Inprise → CodeGear → Embarcadero → Idera).

**Trilha resumida** (siga na ordem; cada etapa tem recursos nas seções abaixo):

1. **Instalação** — baixe o Delphi (Community Edition é gratuita até certo faturamento) e conheça a IDE: Object Inspector, Form Designer e Code Editor.
2. **Sintaxe do Object Pascal** — variáveis, tipos, `begin/end`, `if/case`, laços `for`/`while`, procedures e functions.
3. **Orientação a objetos** — classes, herança, interfaces, propriedades (`property`) e visibilidade (`private`/`protected`/`public`/`published`).
4. **VCL (Windows)** — formulários, componentes visuais, eventos e o padrão de arrastar-e-soltar que dá nome ao "RAD".
5. **Acesso a dados** — FireDAC (o framework de acesso a banco de dados nativo do Delphi), datasets, `TClientDataSet` e relatórios (FastReport).
6. **FireMonkey (FMX)** — a segunda biblioteca visual do Delphi, para apps multiplataforma (desktop, mobile).
7. **Ecossistema** — GetIt Package Manager, gerenciamento de memória, multithreading e testes com DUnitX.
8. **Aplicação** — construa uma API REST com Horse ou DMVCFramework, ou modernize um sistema legado em VCL.

**Por onde começar:**

1. **Baixe o [Delphi Community Edition](https://www.embarcadero.com/products/delphi/starter)**, gratuito para freelancers, estudantes, startups e ONGs (até US$ 5.000 de faturamento anual).
2. **Explore a [LearnDelphi.org](https://learndelphi.org)**, a plataforma oficial de aprendizado da Embarcadero, com trilhas para iniciante, intermediário e avançado.
3. **Assista à playlist oficial [Delphi Boot Camp](https://www.youtube.com/playlist?list=PLwUPJvR9mZHjDFgI9MlNUhH4I7CScwKm0)** no canal da Embarcadero no YouTube.
4. **Leia o [Guia de Delphi da DevMedia](https://www.devmedia.com.br/guia/delphi/38186)**, em português, com mais de 70 conteúdos do zero até relatórios e threads.
5. **Pratique todo dia** nos katas de Pascal do [Codewars](https://www.codewars.com/kata/search/pascal).
6. **Aprofunde com um livro gratuito:** [Mastering Delphi 5 — 2025 Annotated Edition](https://www.marcocantu.com/md52025/), de Marco Cantù.
7. **Construa uma API simples** com o [Horse](https://github.com/HashLoad/horse), um framework web minimalista feito por desenvolvedores brasileiros.
8. **Publique um projeto no GitHub** e explore o que a comunidade já fez em [github.com/topics/delphi](https://github.com/topics/delphi).

Seu primeiro programa em 30 segundos:

```pascal
program OlaDelphi;

{$APPTYPE CONSOLE}

begin
  WriteLn('Olá, Guia Dev Brasil!');
  ReadLn;
end.
```


## 🤖 IA na prática

O Delphi entrou de vez na era da IA: a própria Embarcadero lançou o **Kai**, um assistente de IA agêntico embutido na IDE que já se integra com o Claude, e fornecedores de componentes como TMS e RemObjects lançaram ferramentas próprias de IA para quem programa em Object Pascal. Use a IA como **revisora e tutora**, não como piloto automático — principalmente em um código-base legado que pode ter décadas.

**Para aprender**
- Cole um trecho de código legado (Delphi 7, por exemplo) e peça para a IA **explicar o que ele faz** e sugerir a versão equivalente usando recursos modernos da linguagem (generics, `record` com métodos, `inline var`).
- Peça **exercícios com gabarito** sobre orientação a objetos em Object Pascal (classes, interfaces, propriedades) e resolva antes de olhar a resposta.
- Peça para a IA comparar uma sintaxe do Delphi com a de uma linguagem que você já conhece (C#, Java) — ajuda muito a fixar as diferenças de sintaxe.

**Para trabalhar**
- Use o [GitHub Copilot](https://github.com/features/copilot), o [Cursor](https://cursor.com/) ou o [Claude Code](https://code.claude.com/docs/en/overview) para gerar testes com DUnitX, documentar unidades antigas sem comentários e sugerir refatorações em sistemas legados de VCL.
- O **[Kai](https://blogs.embarcadero.com/an-update-on-kai-and-claude-ai-integration/)** é o assistente de IA agêntico oficial da Embarcadero para o RAD Studio, com integração direta com o Claude dentro da própria IDE (não incluído na Community Edition).
- Depois de **cada** sugestão aceita, compile e rode os testes. Em código legado, um `try/except` "genérico demais" sugerido pela IA pode esconder um bug que já existia há anos.

**Limites e boas práticas**
- Modelos de IA generalistas viram **muito menos código Delphi/Object Pascal** durante o treinamento do que Python ou JavaScript — confira sempre a sintaxe na [documentação oficial](https://pt.wikipedia.org/wiki/Object_Pascal) antes de aceitar.
- Ela tende a confundir sintaxe do Delphi moderno com a de versões antigas (por exemplo, sugerir `WideString` onde hoje se usa `string` normalmente) ou com Free Pascal/Lazarus, que tem pequenas diferenças.
- Não cole código proprietário de sistemas legados, connection strings ou dados de clientes em ferramentas sem a política da sua empresa — muito código Delphi roda em sistemas financeiros e de saúde.
- Entenda o que você aceita: em entrevista e em produção, o código é seu.

**O ecossistema Delphi tem bibliotecas de IA nativas em Object Pascal**, sem precisar sair da linguagem:

- [Kai e a integração com Claude AI (blog oficial)](https://blogs.embarcadero.com/an-update-on-kai-and-claude-ai-integration/) — Post oficial da Embarcadero sobre o assistente de IA agêntico do RAD Studio e sua integração com o Claude.
- [Delphi AI: Ultimate Guide (LearnDelphi.org)](https://learndelphi.org/delphi-ai-ultimate-guide/) — Guia oficial com dezenas de bibliotecas e integrações de IA para Delphi: redes neurais, geração de imagem, visão computacional e mais.
- [TMS AI Studio](https://www.tmssoftware.com/site/tmsaistudio.asp) — Ferramenta comercial da TMS para integrar LLMs (OpenAI, Claude, Gemini, DeepSeek) em aplicações Delphi, com suporte a MCP. Produto pago.
- [RemObjects CodeBot](https://www.remobjects.com/) — Assistente de IA da RemObjects para explicar, gerar, revisar e atualizar código Delphi.
- [DevExpress Documentation MCP Server](https://www.devexpress.com/products/vcl/) — Servidor MCP oficial da DevExpress para consultar a documentação dos componentes VCL diretamente de dentro de assistentes de IA.
- [CodeDroid AI](https://github.com/FMXExpress/CodeDroidAI) — Projeto open source que gera código e formulários Delphi a partir de prompts, usando GPT-4 e outros LLMs.
- [CAI Neural API](https://github.com/joaopauloschuler/neural-api) — Framework de redes neurais nativo em Object Pascal, com suporte a instruções de hardware avançadas e OpenCL, mantido por um desenvolvedor brasileiro.
- [Python4Delphi](https://github.com/lmbelo/python4delphi) — Ponte entre Delphi e Python: dá para usar bibliotecas de IA/ML do Python (TensorFlow, PyTorch) direto de uma aplicação VCL/FMX.
- [TensorFlow.Delphi](https://github.com/Pigrecos/TensorFlow.Delphi) — Bindings para usar o TensorFlow a partir de código Delphi.
- [Keras4Delphi](https://github.com/Pigrecos/Keras4Delphi) — API para construir e treinar redes neurais (convolucionais e recorrentes) em Delphi, inspirada no Keras.
- [Marvin.IA](https://github.com/marvinbraga/Marvin.IA) — Biblioteca de machine learning em Delphi mantida por um desenvolvedor brasileiro.
- [Stable Diffusion Desktop Client](https://github.com/FMXExpress/Stable-Diffusion-Desktop-Client) — Cliente desktop multiplataforma em FireMonkey para geração de imagens com Stable Diffusion.
- [IntelligenceLab](https://www.mitov.com/products/intelligencelab) — Biblioteca comercial de IA para Delphi com redes neurais, Naive Bayes e k-nearest neighbors. Produto pago.
